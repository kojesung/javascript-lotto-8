# 미션 - 로또

# 주요 기능

1. 입력 처리
   - 다음 항목에 대한 입력을 받습니다.
     - 구입 금액
     - 당첨 번호(쉼표로 구분한 6자리)
     - 보너스 번호
   - 잘못된 입력 시 [ERROR] 메세지와 함께 재입력을 요구합니다.
2. 로또 발행
   - 1~45 사이의 서로 다른 6개의 번호를 무작위로 생성합니다.
   - 구매 금액에 따라 (금액 / 로또 가격(1,000원))개의 로또를 자동으로 생성합니다.
3. 당첨 결과 확인
   - 각 로또를 당첨 번호와 비교하여 일치하는 번호의 개수를 구합니다.
   - 보너스 번호 일치 여부도 함께 검사합니다.
   - 도메인 규칙에 따라 등수를 판정합니다.

| 등수 | 조건              | 상금            |
| ---- | ----------------- | --------------- |
| 1등  | 6개 일치          | 2,000,000,000원 |
| 2등  | 5개 + 보너스 일치 | 30,000,000원    |
| 3등  | 5개 일치          | 1,500,000원     |
| 4등  | 4개 일치          | 50,000원        |
| 5등  | 3개 일치          | 5,000원         |

4. 출력 처리
   - 최종 실행 결과에서 나타내는 정보는 다음과 같습니다.
     - 당첨 통계(일치하는 개수와 상금별 개수)
     - 총 수익률

# 클래스 구조

```
src/
 ├── App.js                # 메인 실행 로직
 ├── InputView.js          # 사용자 입력 관리
 ├── OutputView.js         # 콘솔 출력 관리
 ├── InputParser.js        # 입력값 파싱 및 검증
 ├── OutputFormatter.js    # 출력 포맷팅 처리
 ├── Lotto.js              # 로또 객체 정의 및 검증
 ├── LottoGenerator.js     # 로또 자동 발행기
 ├── LottoMatcher.js       # 로또 매칭 및 등수 판별
 ├── LottoResult.js        # 결과 계산 및 통계 관리
 └── constants.js          # 상수 정의
```

# 예외 처리 요약

- 사용자 입력 검증

  - 구입금액 검증
    - 입력값이 비어 있으면 [ERROR] 구입금액을 입력해주세요.
    - 숫자로 변환할 수 없는 경우 [ERROR] 구입금액은 숫자만 입력 가능합니다.
    - 0 이하의 값일 경우 [ERROR] 구입금액은 양수만 입력 가능합니다.
    - 1,000원 단위로 나누어떨어지지 않으면 [ERROR] 구입금액은 1,000원 단위로 입력해야합니다.

- 당첨 번호 검증

  - 입력값이 비어 있으면 [ERROR] 당첨 번호를 입력해주세요.
  - 쉼표(,)로 구분되지 않은 경우 [ERROR] 당첨 번호는 쉼표(,)로 구분해주세요
  - 6개의 숫자가 아닐 경우 [ERROR] 당첨 번호는 6개의 숫자로 이루어져야합니다
  - 숫자가 아닌 값이 포함된 경우 [ERROR] 당첨 번호는 숫자만 입력 가능합니다.
  - 1~45 범위를 벗어나면 [ERROR] 당첨 번호는 1~45 사이의 숫자로 입력해주세요
  - 중복된 숫자가 있을 경우 [ERROR] 당첨 번호는 중복되지 않아야합니다.

- 보너스 번호 검증

  - 입력값이 비어 있으면 [ERROR] 보너스 번호를 입력해주세요.
  - 숫자로 변환할 수 없는 경우 [ERROR] 보너스 번호는 숫자만 입력 가능합니다.
  - 1~45 범위를 벗어나면 [ERROR] 보너스 번호는 1~45 사이의 숫자로 입력해주세요
  - 당첨 번호와 중복될 경우 [ERROR] 보너스 번호는 당첨 번호와 중복되지 않아야합니다.

- 로또 클래스 검증

  - 번호가 6개가 아닌 경우 [ERROR] 로또 번호는 6개여야 합니다.
  - 번호가 중복될 경우 [ERROR] 로또 번호는 중복될 수 없습니다.
  - 번호가 1~45 범위를 벗어나면 [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.

- 로또 생성 클래스 검증

  - 생성할 로또 개수가 정수가 아니면 [ERROR] 로또 개수는 정수여야 합니다.
  - 생성할 로또 개수가 0 이하이면 [ERROR] 로또 개수는 양수여야 합니다.

- 로또 결과 클래스 검증

  - 구입 금액이 유효한 숫자가 아니면 [ERROR] 구입 금액은 유효한 숫자여야 합니다.
  - 구입 금액이 정수가 아니면 [ERROR] 구입 금액은 정수여야 합니다.
  - 구입 금액이 0 이하이면 [ERROR] 구입 금액은 양수여야 합니다.
  - 구매한 로또가 없을 경우 [ERROR] 구매한 로또가 없습니다.

- 로또 매칭 클래스 검증
  - 구매 로또 객체가 정상적인 Lotto 객체가 아닐 경우 [ERROR] 올바른 구매 로또가 아닙니다.(정상적인 Lotto 객체가 아님)
  - 당첨 로또 객체가 정상적인 Lotto 객체가 아닐 경우 [ERROR] 올바른 당첨 로또가 아닙니다.(정상적인 Lotto 객체가 아님)
  - 보너스 번호가 1~45 범위를 벗어나면 [ERROR] 보너스 번호는 1~45 사이의 숫자여야 합니다.

## 입력 처리

- [x] 로또 프로그램 진행을 위한 정보를 입력받는다.
  - `Console.readLineAsync()`를 활용하여 입력받는다.
  - "구입금액을 입력해 주세요."라는 문구로 로또 구입 금액을 입력받는다.
  - "당첨 번호를 입력해 주세요."라는 문구로 당첨 번호를 입력 받고 번호는 쉼표(,)를 기준으로 구분한다.
  - "보너스 번호를 입력해 주세요."라는 문구로 보너스 번호를 입력 받는다.
  - 사용자가 잘못된 값을 입력할 경우 에러를 발생시킨 후 해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받는다.

## 출력 처리

- [x] 로또 프로그램 진행 과정을 알 수 있도록 출력 처리한다.

  - `Console.print()`를 활용하여 출력한다.
  - `${n}개를 구매했습니다.`의 형식으로 구매한 로또 수량을 출력한다.
  - `[number1, number2, number3, number4, number5, number6]`(오름차순)의 형식으로 번호를 출력한다.

- [x] 로또 프로그램 결과를 알 수 있도록 출력 처리한다.

  - 형식에 맞도록 당첨 통계를 출력한다.

## 로또

- [x] 6자리의 로또 번호를 관리할 수 있는 클래스를 만든다.

  - 숫자의 출처는 상관없이 로또 번호를 관리할 수 있도록 한다.

## 파싱

- [x] 사용자 입력 파싱
  - 사용자가 입력한 금액을 숫자로 파싱한다.
  - 사용자 입력으로 생성된 당첨 번호를 `[number1, number2, number3, number4, number5, number6]`과 같은 형식으로 파싱한다.
  - 사용자에게 입력받은 보너스 번호를 숫자로 파싱한다.

## 로또 발행

- [x] 구입 금액에 맞는 개수의 로또를 생성한다.
  - 구입 금액을 1,000으로 나눈 개수만큼 로또를 생성한다.
  - `MissionUtils.Random.pickUniqueNumbersInRange(1, 45, 6)`를 사용하여 로또 번호를 생성한다.

## 당첨 확인

- [x] 구매한 로또와 당첨 번호를 비교한다.

  - 각 로또에서 당첨 번호와 일치하는 개수를 센다.
  - 보너스 번호 일치 여부를 확인한다.

- [x] 당첨 등수를 결정한다.

  - 6개 일치: 1등 (2,000,000,000원)
  - 5개 일치 + 보너스: 2등 (30,000,000원)
  - 5개 일치: 3등 (1,500,000원)
  - 4개 일치: 4등 (50,000원)
  - 3개 일치: 5등 (5,000원)

## 수익률 계산

- [x] 등급별 당첨 개수와 총 당첨금을 구한다.

- [x] 수익률을 계산한다.
  - (총 당첨 금액 / 구입 금액) × 100
  - 소수점 둘째 자리에서 반올림한다.

## 출력 포맷팅

- [x] 당첨 통계를 출력 형식으로 변환한다.

  - "3개 일치 (5,000원) - n개" 형식으로 변환한다.
  - 구분선 "---"을 추가한다.

- [x] 수익률을 출력 형식으로 변환한다.
  - "총 수익률은 n%입니다." 형식으로 변환한다.

## 상수 정의

- [x] 매직 넘버를 상수로 정의한다.

    - 사용자가 입력한 금액이 1,000원 단위로 나누어떨어지지 않을 경우 "[ERROR] 구입금액은 1,000원 단위로 입력해야합니다." 메세지와 함께 `Error`를 발생시킨다.

    - 사용자가 입력한 당첨 번호가 6개의 숫자가 아닌 경우 "[ERROR] 당첨 번호는 6개의 숫자로 이루어져야합니다" 메세지와 함께 `Error`를 발생시킨다.

  - 보너스 번호 검증
    - 사용자가 입력한 보너스 번호가 숫자로 변환할 수 없을 경우 "[ERROR] 보너스 번호는 숫자만 입력 가능합니다." 메시지와 함께 `Error`를 발생시킨다.
    - 사용자가 입력한 보너스 번호가 1개의 숫자가 아닌 경우 "[ERROR] 보너스 번호는 1개의 숫자로 이루어져야합니다" 메세지와 함께 `Error`를 발생시킨다.
    - 사용자가 입력한 보너스 번호가 1~45 범위가 아닌 경우 "[ERROR] 보너스 번호는 1~45 사이의 숫자로 입력해주세요" 메세지와 함께 `Error`를 발생시킨다.
