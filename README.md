# 미션 - 로또

## 입력 처리

- [x] 로또 프로그램 진행을 위한 정보를 입력받는다.
  - `Console.readLineAsync()`를 활용하여 입력받는다.
  - "구입금액을 입력해 주세요."라는 문구로 로또 구입 금액을 입력받는다.
  - "당첨 번호를 입력해 주세요."라는 문구로 당첨 번호를 입력 받고 번호는 쉼표(,)를 기준으로 구분한다.
  - "보너스 번호를 입력해 주세요."라는 문구로 보너스 번호를 입력 받는다.

## 출력 처리

- [ ] 로또 프로그램 진행 과정을 알 수 있도록 출력 처리한다.

  - `Console.print()`를 활용하여 출력한다.
  - `${n}개를 구매했습니다.`의 형식으로 발행한 로또 수량을 출력한다.
  - `[number1, number2, number3, number4, number5, number6]`(오름차순)의 형식으로 번호를 출력한다.

- [ ] 로또 프로그램 결과를 알 수 있도록 출력 처리한다.

  - 형식에 맞도록 당첨 통계를 출력한다.

## 로또

- [ ] 6자리의 로또 번호를 관리할 수 있는 클래스를 만든다.

  - 숫자의 출처는 상관없이 로또 번호를 관리할 수 있도록 한다.

## 파싱

- [ ] 로또 번호 파싱한다.
  - 사용자가 입력한 금액을 숫자로 파싱한다.
  - 사용자 입력으로 생성된 당첨 번호를 `[number1, number2, number3, number4, number5, number6]`과 같은 형식으로 파싱한다.
  - `MissionUtils.Random.pickUniqueNumbersInRange()`로 발행한 로또 번호를 `[number1, number2, number3, number4, number5, number6]`과 같은 형식으로 파싱한다.
  - 사용자에게 입력받은 보너스 번호를 숫자로 파싱한다.

## 로또 발행

- [ ] 구입 금액에 맞는 개수의 로또를 생성한다.
  - 구입 금액을 1,000으로 나눈 개수만큼 로또를 생성한다.
  - `MissionUtils.Random.pickUniqueNumbersInRange(1, 45, 6)`를 사용하여 로또 번호를 생성한다.

## 당첨 확인

- [ ] 구매한 로또와 당첨 번호를 비교한다.

  - 각 로또에서 당첨 번호와 일치하는 개수를 센다.
  - 보너스 번호 일치 여부를 확인한다.

- [ ] 당첨 등수를 결정한다.

  - 6개 일치: 1등 (2,000,000,000원)
  - 5개 일치 + 보너스: 2등 (30,000,000원)
  - 5개 일치: 3등 (1,500,000원)
  - 4개 일치: 4등 (50,000원)
  - 3개 일치: 5등 (5,000원)

- [ ] 등급별 당첨 개수와 총 당첨금을 구한다.

## 수익률 계산

- [ ] 수익률을 계산한다.
  - (총 당첨 금액 / 구입 금액) × 100
  - 소수점 둘째 자리에서 반올림한다.

## 출력 포맷팅

- [ ] 로또 번호를 출력 형식으로 변환한다.

  - 오름차순으로 정렬한다.
  - `[n1, n2, n3, n4, n5, n6]` 형식으로 변환한다.

- [ ] 당첨 통계를 출력 형식으로 변환한다.

  - "3개 일치 (5,000원) - n개" 형식으로 변환한다.
  - 구분선 "---"을 추가한다.

- [ ] 수익률을 출력 형식으로 변환한다.
  - "총 수익률은 n%입니다." 형식으로 변환한다.

## 상수 정의

- [ ] 매직 넘버나 필요한 고정으로 출력될 문자열을 상수로 정의한다.

## 예외 처리

- [ ] 사용자 입력 검증
  - 구입금액 검증
    - 사용자가 입력한 금액이 숫자로 변환할 수 없을 경우 "[ERROR] 구입금액은 숫자만 입력 가능합니다." 메시지와 함께 `Error`를 발생시킨다.
    - 사용자가 입력한 금액이 1,000원 단위로 나누어떨어지지 않을 경우 "[ERROR] 구입금액은 1,000원 단위로 입력해야합니다." 메세지와 함께 `Error`를 발생시킨다.
    - 사용자가 입력한 금액이 양수로 변환할 수 없을 경우 "[ERROR] 구입금액은 양수만 입력 가능합니다." 메시지와 함께 `Error`를 발생시킨다.
  - 당첨 번호 검증
    - 사용자가 입력한 당첨 번호가 쉼표(,)로 구분되어 있지 않은 경우 "[ERROR] 당첨 번호는 쉼표(,)로 구분해주세요" 메세지와 함께 `Error`를 발생시킨다.
    - 사용자가 입력한 당첨 번호가 6개의 숫자가 아닌 경우 "[ERROR] 당첨 번호는 6개의 숫자로 이루어져야합니다" 메세지와 함께 `Error`를 발생시킨다.
    - 사용자가 입력한 당첨 번호가 1~45 범위가 아닌 경우 "[ERROR] 당첨 번호는 1~45 사이의 숫자로 입력해주세요" 메세지와 함께 `Error`를 발생시킨다.
  - 보너스 번호 검증
    - 사용자가 입력한 보너스 번호가 숫자로 변환할 수 없을 경우 "[ERROR] 보너스 번호는 숫자만 입력 가능합니다." 메시지와 함께 `Error`를 발생시킨다.
    - 사용자가 입력한 보너스 번호가 1개의 숫자가 아닌 경우 "[ERROR] 보너스 번호는 1개의 숫자로 이루어져야합니다" 메세지와 함께 `Error`를 발생시킨다.
    - 사용자가 입력한 보너스 번호가 1~45 범위가 아닌 경우 "[ERROR] 보너스 번호는 1~45 사이의 숫자로 입력해주세요" 메세지와 함께 `Error`를 발생시킨다.
    - 사용자가 입력한 보너스 번호가 기존에 입력한 당첨 번호와 중복되는 경우 "[ERROR] 보너스 번호는 당첨 번호와 중복되지 않아야합니다." 메세지와 함께 `Error`를 발생시킨다.
